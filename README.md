# صرّاف بوك — sarraf-book

تطبيق شخصي لإدارة الحوالات والعمولات والصندوق. يعمل دون إنترنت (PWA) ويحفظ البيانات على الجهاز (IndexedDB).

## التشغيل
```
npm install
npm run dev        # للتطوير: http://localhost:5173
npm test           # اختبارات الدوال المالية (Vitest)
npm run build      # نسخة الإنتاج في dist/
npm run preview    # تجربة نسخة الإنتاج (مع العمل دون اتصال)
```

## البنية
| المسار | المحتوى |
|---|---|
| `src/lib/money.ts` | تحويل/تنسيق المبالغ كأعداد صحيحة (بدون float)، أسعار الصرف |
| `src/lib/commission.ts` | حساب العمولة (نسبة/ثابت/شرائح، حد أدنى/أقصى) واختيار القاعدة |
| `src/lib/aggregate.ts` | أرصدة الصندوق وتجميع التقارير |
| `src/db/db.ts` | مخطط Dexie — أي تغيير = `version(N+1)` جديدة مع ترحيل |
| `src/db/ops.ts` | العمليات: إضافة/صرف/إلغاء/تعديل حوالة، الصندوق، الجرد، النسخ الاحتياطي |
| `src/pages/*` | الشاشات |
| `src/index.css` | ألوان الهوية البصرية (متغيرات CSS في مكان واحد) |

## ملاحظات
- المبالغ تُخزَّن بأصغر وحدة: الشيكل/الدولار/اليورو بخانتين، والدينار بثلاث (فلس).
- النسب بنقاط الأساس (1.5% = 150)، وأسعار الصرف × 1,000,000.
- لا حذف للحوالات: الإلغاء يغيّر الحالة ويُرجع المبلغ للصندوق إن كانت مصروفة.
