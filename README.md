# صرّاف بوك — sarraf-book

تطبيق شخصي لإدارة الزبائن والحوالات والعمولات. يعمل دون إنترنت (PWA) ويحفظ البيانات على الجهاز (IndexedDB).

**التطبيق المنشور:** https://baselraida.github.io/Sarraf-Book/

## التشغيل
```
npm install
npm run dev        # للتطوير: http://localhost:5173
npm test           # اختبارات الدوال المالية (Vitest)
npm run build      # نسخة الإنتاج في dist/
npm run preview    # تجربة نسخة الإنتاج (مع العمل دون اتصال)
```

## النشر
كل دفع (push) إلى `main` يبني التطبيق وينشره تلقائياً على GitHub Pages عبر `.github/workflows/deploy.yml`.
مرة واحدة فقط: في إعدادات المستودع ← Pages ← Source اختر **GitHub Actions**.

## البنية
| المسار | المحتوى |
|---|---|
| `src/lib/money.ts` | المبالغ كأعداد صحيحة (بدون float)، النسب، أسعار الصرف |
| `src/lib/calc.ts` | العمولة، والتحويل للزبون (كامل/جزء/لاحقاً) وربح فرق السعر |
| `src/lib/aggregate.ts` | أرصدة الزبائن، أرصدتي، الأرباح، والتقارير |
| `src/db/db.ts` | مخطط Dexie وترحيل الإصدار 1 → 2 — أي تغيير = `version(N+1)` جديدة |
| `src/db/ops.ts` | العمليات والدفعات والزبائن والصندوق والنسخ الاحتياطي |
| `src/pages/*` | الشاشات |
| `src/index.css` | ألوان الهوية البصرية (متغيرات CSS في مكان واحد) |

## ملاحظات
- المبالغ بأصغر وحدة: الشيكل/الدولار/USDT/اليورو بخانتين، والدينار بثلاث (فلس).
- النسب بنقاط الأساس (2% = 200)، وأسعار الصرف × 1,000,000.
- لا حذف نهائي: الإلغاء يغيّر الحالة فقط ويبقى في السجل.
- البيانات محفوظة في متصفح الجهاز فقط — خذ نسخة احتياطية دورياً من الإعدادات.
